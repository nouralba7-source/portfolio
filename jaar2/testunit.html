Over dit project

Op het dak van het USP staat een testunit met sensoren die continu data meten. Voor dit project heb ik een interactief dashboard gebouwd waarmee je de meetdata kunt bekijken en analyseren. [Schrijf hier jouw eigen beschrijving: wat meet de unit precies, wat heb jij gebouwd en wat kun je ermee?]

Tools gebruikt
Python Streamlit Pandas Plotly Sensordata
Hoe werkt het dashboard?
  • 📡
    Data inladen De sensordata wordt ingeladen vanuit een CSV-bestand met Python (Pandas).
  • 📈
    Visualisatie Plotly maakt de interactieve grafieken: je kan inzoomen, een periode selecteren en waarden vergelijken.
  • 🌐
    Online zetten Het dashboard draait op Streamlit Cloud en is via een link deelbaar.
